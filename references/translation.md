# 播客中文精修标准

目标是自然的中文访谈表达。以英文核对事实、数字、否定、条件、因果和语气；可以重组语序、拆分长句、收敛无实义的口头填充词。保留所有观点、案例与限定，不以流畅为理由摘要化。

英文比喻按上下文转为可理解的中文；不添加网梗、名人口吻或原文不存在的例子。专名首次中文加英文，后续统一；没有通行译名保留英文。字幕疑似错误放入 notes，注明不确定性，不擅改英文。翻译对不确定含义采用保守表达。

每篇建立简短术语表。审校重点是漏译、误译、直译腔和全文术语一致性，不输出冗长自我评价。省 token 优先固定模板、分章节处理和复用术语表；不能省略英文核对和必要审校。

## 逐段语义对齐审校

程序校验（来源覆盖、英文一致）通过后，还必须逐段做语义对齐审校：

- 每段中文只能对应该段英文。逐段核对数字、否定、条件、因果、人物关系和语气，确认没有把相邻段落的内容提前、后移、重复或遗漏（尤其注意字幕切句点落在句子中间时，中文不能跟着错位）。
- 分段边界调整后，必须同步重新检查受影响段落的中文归属，逐段确认中英对应关系仍成立。
- 习语按语境意译，不机械替换：例如 lock in 视上下文译"进入专注状态/全身心投入"而非"锁定期"。比喻修饰词（如 dirty 形容燃料时）按所在上下文理解其具体含义（如燃料的来路、性质、情感色彩），译成自然中文，不固定映射为单一译法。routine 在口语里可译"惯例/固定节奏"而非照搬英文。
- 保留原文的自我纠正、犹豫、说错再改口等语气细节，不以"更流畅"为理由抹平。
- 修订结果与原因记录到简短审校记录（段落编号、问题、理由、前后对照）。

## 标题与广告呈现

标题译为自然中文，不夸大原意，同时完整保留英文原题。双语标题及广告的页面呈现以 SKILL.md 的“标题与广告的呈现规则”为准。
